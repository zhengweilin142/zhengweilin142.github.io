单文件纯静态个人主页：**无框架、无构建步骤、无任何外部依赖**（不引用 CDN、不加载第三方字体），直接托管在 GitHub Pages 上。

🌐 线上地址：**https://zhengweilin142.github.io/**

## 目录结构

```
.
├── index.html                       个人主页（HTML + 内联 CSS + 内联 JS）
├── knowledge-base/                  企业知识库 Demo 项目展示页
│   ├── index.html                   展示页本体（单文件）
│   └── assets/                      两张真实界面截图
```

两个页面各自都是 **一个自包含的 HTML 文件**（样式与脚本全部内联），改完直接提交即可，没有构建步骤。

## 本地预览

```powershell

start index.html

# 方式二：起一个静态服务器（行为与线上一致）
python -m http.server 8080

```

## 自检

```powershell
node tools/site-check.js
```

检查项：

- 模板占位内容（示例姓名、示例邮箱、`href="#"`）是否清干净
- 所有标签是否闭合
- **隐私**：不含手机号、性别、年龄、政治面貌、求职意向
- 四个开源项目链接是否都在

## 企业知识库展示页

`knowledge-base/` 是一个独立的展示页，用来介绍「企业知识库 Demo」那个 RAG 项目：

- 两段式检索流程图（广召回 → RRF 融合 → Cross-Encoder 精排 → 带编号回答）
- 两张真实界面截图
- **标定实验数据**：无关问题余弦 0.637 反而高于真相关问题 0.454，证明纯阈值方案必然失败
- 技术选型理由（为何不用 PyTorch / ChromaDB / LangChain）与 6 条实测弯路记录
- 迁移到企业环境需要改动的地方

页面内容全部取自该项目 README 的实测结论，没有夸大。底部明确标注了
「静态展示，非在线服务」与「示例文档均为虚构内容」。主页的知识库卡片通过「项目详情」链接进入这里。

## 隐私说明（重要）

本站是公开页面，因此有意排除了简历里的以下信息：

- ❌ 手机号
- ❌ 性别、年龄、政治面貌
- ❌ 求职意向（意向城市 / 求职类型）

`tools/site-check.js` 里有对应的隐私断言，如果不小心把这些信息加回页面，自检会直接失败。
脚本用**通用手机号模式**做检测，自身不含任何真实号码——否则测试文件自己就成了泄露源。

## 技术说明

- **单文件**：无构建、无依赖，双击即可本地打开，也可以直接丢到任何静态托管
- 支持**深色 / 浅色主题切换**（右上角按钮），选择会记在 localStorage
- 响应式：桌面 / 平板 / 手机自适应，窄屏时导航收进汉堡菜单
- 滚动进场动画、数字滚动计数、回到顶部按钮
- 保留了一个「占位链接提醒」：如果以后加了 `href="#"` 的链接，点击时会弹出提示提醒你换成真实地址
